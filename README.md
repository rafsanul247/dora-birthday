# Doraemon Birthday Universe 💙

A cinematic, responsive birthday microsite built with Next.js, React, Tailwind CSS v4 and CSS animations.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Highlights

- Cinematic dark-blue birthday landing page
- CSS-built Doraemon-inspired character
- Parallax mouse movement and floating objects
- Animated stars, aurora, glow and orbit effects
- Interactive wish cards
- Animated Anywhere Door
- Confetti celebration
- Secret-message modal
- Responsive mobile layout
